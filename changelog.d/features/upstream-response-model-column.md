- **feat(logs):** the request-logs list and detail modal now surface the _upstream actual model_ for Responses-API traffic. When the upstream's own `response.completed` payload declares a model that differs from the routed one (the sub2api-style observation — terminal snapshot wins, chat-completion summaries don't count), the new **Upstream Model** column shows it in red, and the detail modal repeats it under the Model field. Rows without a differing declaration (non-Responses upstreams, no model declared, or an exact match) stay empty. Stored in the new `call_logs.upstream_response_model` column (migration 186) plus the `_omniroute` response meta blob; log-only, billing is unchanged.
